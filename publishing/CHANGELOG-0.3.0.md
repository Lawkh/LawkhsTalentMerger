# 0.3.0

Initial public version.

- Detect duplicate talent loadouts by selected talent nodes and ranks, including Hero Talents.
- Display duplicate groups using matching colors in the addon and native talent dropdown.
- Merge duplicate groups with a suggested combined name.
- Preview and confirm duplicate cleanup, retaining the first loadout in each group.
- Delete all saved loadouts with the exact NUKE confirmation word.
- Process deletions sequentially with server confirmation, progress and a Stop action.
- Use a single window for the list and confirmations.
- Block changes during combat, while dead, or with pending talent changes.
- Keep talent export backups for the last 10 operations.
- Add automatic localization for all supported WoW client languages.
