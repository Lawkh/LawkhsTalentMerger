# 0.4.0

- Add a Nuke column for each specialization, with native specialization icon, name, loadout count and an independently scrolling list.
- Allow deletion of a single specialization or any selected combination.
- Start with no specialization selected; disable empty specializations.
- Require the exact NUKE word again whenever the selection changes.
- Validate and back up only the selected specializations. Changes in unchecked specializations do not affect the confirmed deletion.
- Keep the single-window navigation, progress, Stop action and combat checks.
- Localize the new selection controls in all supported client languages.
- Make the test runner return a failure status for Lua runtime errors.
